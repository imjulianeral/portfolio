# Portfolio [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/dillionverma/portfolio)

Built with TanStack Start, [shadcn/ui](https://ui.shadcn.com/), and [magic ui](https://magicui.design/).

# Features

- Setup only takes a few minutes by editing the [single config file](./src/data/resume.tsx)
- Built using TanStack Start, React, Typescript, Shadcn/UI, TailwindCSS, Motion, Magic UI
- Includes a blog
- Responsive for different devices

# Getting Started Locally

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/dillionverma/portfolio
   ```

2. Move to the cloned directory

   ```bash
   cd portfolio
   ```

3. Install dependencies:

   ```bash
   nub install
   ```

4. Start the local server:

   ```bash
   nub run dev
   ```

5. Open the [config file](./src/data/resume.tsx) and make changes
